Drive X rclone

개인정보처리방침

시행일 2026년 11월 14일

접근하는 Google 데이터

운영자가 Google Drive 접근에 동의하면 로컬 rclone은 OAuth 인증 정보를 받습니다. 드라이브를 표시하고 파일 탐색기 작업을 처리하기 위해 폴더 구조, 파일 이름과 속성, 저장 용량을 조회합니다. 운영자가 요청한 경우 파일 내용을 읽거나 파일을 추가, 수정, 이동 또는 삭제합니다.

이용 목적과 저장

Google 데이터는 운영자의 Windows PC에 Google Drive를 연결하고 운영자가 수행하는 파일 작업을 처리하는 데 사용됩니다. 연결을 유지하기 위한 인증 정보는 로컬 rclone 설정 파일에 저장됩니다. 파일 데이터와 파일 작업 기록은 로컬 캐시와 로그에 남을 수 있습니다. 작업을 처리할 때 rclone은 Google Drive API와 통신합니다.

공유 및 보호

이 앱은 Google Drive 데이터나 OAuth 인증 정보를 홈페이지로 보내지 않으며 광고, 판매, 이용자 분석 또는 AI 모델 학습에 사용하지 않습니다. Google API에서 받은 정보의 사용과 이전에는 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건이 적용됩니다. GitHub Pages가 홈페이지를 호스팅하며 웹사이트 접속에 관한 정보는 GitHub 개인정보처리방침에 따라 처리됩니다.

연결 해제와 데이터 삭제

운영자는 Google 계정의 서드 파티 연결에서 앱 접근 권한을 철회할 수 있습니다. 로컬 인증 정보와 캐시 및 로그는 rclone을 종료한 뒤 해당 PC에서 삭제할 수 있습니다. Google Drive 원본은 Google Drive에서 관리합니다.

문의

개인정보 관련 문의는 Google 동의 화면에 표시되는 앱 지원 이메일로 보낼 수 있습니다.
